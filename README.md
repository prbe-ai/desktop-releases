# Probe desktop releases

This repository only hosts builds of the Probe desktop app for macOS (one universal build for
Apple Silicon and Intel). The app's source is private; there is no code here.

Download `Probe.dmg` from the [latest release](https://github.com/prbe-ai/desktop-releases/releases/latest).
Installed copies update themselves from `latest.json` in that release.

Builds are published by CI. Questions or problems: support@prbe.ai.
